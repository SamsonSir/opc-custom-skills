# 巨量千川站点经验

## 平台特征

- 创建页是高动态 SPA，元素 ref 会频繁重排。
- “上传视频”不是稳定的标准文件输入控件。
- 页面上出现“上传成功”不等于主计划已经挂上了该视频。
- 商品搜索结果可能出现“商品已下架”，这不是脚本异常，是业务状态。

## 已验证的稳定路径

### 浏览器会话

- 只复用 `9222`。
- 必须连接用户已有登录态的 Chrome。

### 从首页进入创建页

常见起点：

`https://qianchuan.jinritemai.com/home?aavid=...&from_qc_login=1`

这是千川首页，不是投放创建页。投流自动化不要从这里长时间盲点找路。

目标创建页：

`https://qianchuan.jinritemai.com/uni-creation/product?aavid=<aavid>`

实测注意：

- 裸跳 `/uni-creation/product` 可能被重定向到 `/login` 选择账户页。
- 从首页数据概览区域点击 `新建计划` 会打开 `/uni-creation/live?...`，这是直播全域投放，不是商品全域投放。
- 商品全域投放页面 title 是 `商品全域投放`，正文会出现 `选择要投放的商品`、`添加商品`、`日预算`、`净成交 ROI`、`自选投放素材`、`发布计划`。

稳定策略：

1. 通过 `http://127.0.0.1:9222/json/list` 枚举所有 tab。
2. 优先复用 URL 包含 `/uni-creation/product` 的 tab。
3. 如果只有 `/home` tab，从 URL 提取 `aavid`，用 CDP 打开 `/uni-creation/product?aavid=<aavid>`。
4. 如果进入 `/login` 选择账户页，按目标账户名或 ID 点击账号，回到 `/home?aavid=...` 后再执行第 3 步。
5. 如果直达失败或回到首页，再只尝试首页入口词：`商品全域投放`、`商品投放`、`投放商品`、`控成本投放`、`推商品`。
6. 如果仍不能到达创建页，停止探索并让用户手动打开创建页；不要为了找路径无限截图、点击、搜索。

创建页判定：

- URL 包含 `/uni-creation/product`。
- 页面正文同时出现投放配置相关词，如 `商品`、`预算`、`ROI`、`添加视频`、`发布计划`。
- 页面仍是 `/home` 或只出现首页概览、账户、数据类内容时，不要调用上传脚本。
- URL 包含 `/uni-creation/live` 时必须切走，这是直播全域投放。

### 本地视频上传

前置条件：

- `选择要添加素材的商品` 必须先选中当前商品；未选中时页面会提示 `请先选择要添加创意的商品`，此时点 `添加视频` 不会稳定打开素材弹层。
- 如果普通点击下拉不展开，DOM 中可能已有隐藏的 `.creative-multi-products-select .ovui-option`，可通过 CDP 点击包含目标商品 ID 的 option。选中后主页面会显示商品名和数量 `1`，并且“不先选择商品”的提示消失。

1. 打开 `添加视频`
2. 切到 `上传视频`
3. 切来源到 `本地上传`
4. 不依赖系统文件窗口手工点选
5. 使用 CDP 的 `Page.setInterceptFileChooserDialog + DOM.setFileInputFiles`
6. 等待站点完成上传
7. 在弹层中勾选成功的视频
8. 点击 `确定`
9. 回到主页面后核对 `视频 (n)`

补充：

- 当前稳定边界是“上传完成后勾选素材并关闭弹窗”。
- `upload_local_videos.js` 不要继续大改“打开上传抽屉/触发 file chooser”这一段。
- 不要为了验证“干净页”在视频已成功上传/回填后再加 `_qc_reset_ts`；这会清空当前创建页视频。
- 如果主页面已经出现足够数量的 `视频 (n)`，创建脚本应跳过重复上传。
- 如果上传弹窗里已能看到同名视频且状态不是百分比/取消上传，上传脚本可以直接复用当前弹窗可见素材，走“勾选 -> 确定”。
- 批量上传时不要只等总超时；某个视频进度长时间卡在非 100% 状态，应删除该视频行并只重传该文件。
- 重传次数需要有上限，避免坏素材无限循环；超过上限后应输出失败原因，让操作者回到素材处理阶段。
- 更稳的策略是先由创建页脚本把页面状态带到：
  - `自选投放素材` 已开启
  - 创意商品已选中
  - `添加视频` 按钮可点
  - 需要时抽屉已处于 `上传视频` 页签
  再调用上传脚本。

### 商品回填判定

- 商品弹窗确认后，主页面不一定总是明显展示商品 ID。
- 成功判定不要只靠“页面上看到了目标商品 ID”。
- 更稳的信号是：
  - `已添加：1/30`
  - `继续添加商品`
  - 商品卡已出现
- 如果商品弹窗已经关闭，但主页面已经是单商品状态，不要再回头找商品弹窗，更不要立即刷新。

### 自选素材开关

- `自选投放素材` 必须只点该卡片自己的 checkbox。
- 不要点击整张大卡，不要模糊命中 `智能优选素材` 区域。
- 开启成功判定必须同时满足：
  - `自选投放素材` checkbox 已勾选
  - `添加视频` 按钮可见

### 创意商品选择

- 不要在整页 DOM 里搜商品 ID 后随手点到第一个 checkbox。
- 正确作用域是 `选择商品：` 下拉弹层内部的 option 列表。
- 如果主页面已经显示 `选择商品：<商品名>` 且不是 `请选择`，可直接视为创意商品已选中。

## 已知陷阱

### 1. 不是标准 file input

`agent-browser upload` 往往会报：

- `Node is not a file input element`

这不是路径问题，是站点控件实现方式的问题。

如果 `scripts/upload_local_videos.js` 报：

- `没有拦截到文件选择器，请确认页面处于“上传视频 -> 本地上传”。`

优先恢复步骤：

1. 确认素材商品已选中。
2. 手动或用 `agent-browser` 点击主页面 `添加视频`。
3. 在弹层里点击 `上传视频`。
4. 看到 `将文件拖拽到此处，或 点击上传` 后，再重新运行上传脚本。
5. 上传过程中不要因为脚本短暂返回就直接判断失败，先等 15-30 秒重新 snapshot；平台可能仍在上传并自动勾选合格视频。
6. 但如果单个视频进度长时间不动且未达到 100%，不要继续原地等；删除该视频行后重传该文件。

### 2. 中文文件名兼容差

- 中文文件名并非一定失败，但实际执行中更容易出现识别异常或状态不同步。
- 优先使用英文、数字、下划线文件名。

### 3. 上传成功 != 计划已挂载

- 网络层可能已经完成 `finish`、`bind-video-to-owner`
- 但主页面仍然是 `视频 (1)`

这说明视频已经进素材库，但没有挂回当前计划。  
处理方式：继续在当前弹层勾选成功视频并点 `确定`。

### 4. 平台会拒绝不合规视频

已出现过的错误：

- `素材尺寸（宽度）不符合规范，请检查后重新上传`
- `素材尺寸（ 宽度 ）不符合规范，请检查后重新上传`

遇到这种情况，不要重试同一文件，直接换视频。

### 5. “我的视频”与“上传视频”都可能被用到

- 常规路径优先在 `上传视频` 页签完成上传和勾选
- 如果上传完成但没有成功回填计划，再考虑回到 `我的视频`，来源切到 `本地上传` 后选回

### 6. ROI 页面建议值不等于业务目标值

- 页面会给出自己的 `净成交ROI建议值`，例如 `3.68`。
- 该值不能直接拿来投放；如果用户已给 `售价/成本/签收率`，必须按业务口径重算并回填。
- 当前已验证：
  - `售价299 / 成本40 / 签收50%` -> 页面填 `2.80`
  - `售价299 / 成本40 / 签收55%` -> 页面填 `2.54`

### 7. 标题区默认未展开

- 主页面只看到 `添加标题` 不代表标题已完成。
- 需要先点击 `添加标题`，再寻找 placeholder 为 `请输入标题或使用系统推荐标题` 的输入框。
- 发布前必须确认标题输入框里确实有值，且每条标题长度为 5-55 字。
- 千川会自动保留一个空的“新增标题”输入行；不要反复填这个空行，否则页面会不断追加新的空行。
- 正确处理是最多保留 3 条有效且不重复的标题，多余标题行点击右侧删除图标清理。
- 如果提示 `标题长度必须为 5-55` 或 `请输入5-55个字的创意标题`，先关闭错误提示/弹窗，再清理空标题行，不能继续发布。

### 8. 发布确认弹窗

- 点击 `发布计划` 后可能出现“为保证全域投放的唯一性”的二次确认弹窗。
- 脚本必须先勾选 `不再提示`，再点击弹窗内的 `确认发布`。
- 如果已经勾过 `不再提示`，后续可能不会再弹出二次确认框；这不是失败。
- 不要固定先等确认弹窗。点 `发布计划` 后应并行检测确认弹窗、发布失败提示、投放管理页跳转。
- 无二次确认弹窗时，应快速进入发布结果检测，不要白等 15 秒。
- 发布失败 toast 可能先于最终成功跳转出现；不要立即判失败，需给约 6 秒宽限期观察是否跳到投放管理。
- 发布成功可用以下信号判断：
  - 页面跳转到投放管理页。
  - URL 包含 `/uni-prom`。
  - 当前页不再出现 `发布计划` 按钮。

## 页面判定要点

- `视频 (n)` 是主页面最终判定，不是弹层临时状态。
- 发布前必须看到素材数、标题、预算、ROI 都已回填。
- 默认脚本只停在发布前；只有显式 `--publish` 才点击 `发布计划`。
- 点击 `发布计划` 后若出现确认弹窗，优先点击弹窗作用域内的 `确认发布`；弹窗带 `不再提示` 时先勾选。
- `发布计划` 默认不执行；只有用户明确授权或脚本显式传 `--publish` 时才发布。
